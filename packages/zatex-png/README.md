# zatex-png

KaTeX-compatible LaTeX → PNG screenshots for the zatex monorepo.
macOS-only backend (CoreGraphics + CoreText); the layout core stays
portable. Strict hierarchy: `zatex-png` depends on `zatex(-core)`,
never the reverse, and no layout math lives in this package — it only
scales the core's integer font units to pixels and draws.

## Usage

```
zatex-png [--display] [--px N] [--font PATH] "<tex>" out.png
zatex-png --corpus PATH --outdir DIR [--px N] [--font PATH]
```

Defaults: 48 px per em, `../zatex-core/fixtures/fonts/latinmodern-math.otf` (the
pinned fixture, so same input renders identical pixels). Batch mode
renders every `accept` row of the corpus to `<id>.png`, skips rejects,
and exits nonzero if any accept row fails to lay out.

## Layout

- `src/main.zig` — CLI (single formula or corpus batch).
- `src/render.zig` — IR → pixels (coordinate mapping + PNG writing).
- `src/cg.zig` — manual CoreGraphics/CoreText/ImageIO bindings.
- `src/font.zig` — font loading + advances for the core provider.
- `screenshots/` — visual regression set: curated corpus, checked-in
  baseline PNGs, and `render.sh`. See `screenshots/README.md`.

`docs/katex-syntax.md` (repo root) mirrors the KaTeX support table with
a render per accepted function, generated by `tools/gen_doc_renders.py`.
