# zatex-svg Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `packages/zatex-svg`: LaTeX math → standalone, self-contained SVG (outlined glyph paths) over the `zatex` core, heavily tested, wired into CI, delivered as PR `feat/zatex-svg` → `main`.

**Architecture:** Thin geometric walker over `ir.Layout` (runs + rules). Glyph ink comes from the font files themselves — CFF/Type2 outlines via the `zatex` package's host-side `cff` module, demuxed per stack face through `faceOf`. Transforms bake into path coordinates with PNG's exact order; positions need no flip (core and SVG are both y-down) but outline y negates about the baseline (CFF is y-up).

**Tech Stack:** Zig 0.16.0 only, zero dependencies. Library path allocates nothing (caller-owned buffers, `NoSpace` on overflow).

**Spec:** `docs/superpowers/specs/2026-09-27-zatex-svg-design.md` — the plan argues from the spec; executors read both.

## Global Constraints

- Zig 0.16.0 (`minimum_zig_version = "0.16.0"`); test gate is `cd packages/zatex-svg && zig build test --summary all`.
- Library path: zero heap allocations; every buffer caller-owned; exhaustion is `error.NoSpace`, never a panic; total on adversarial input.
- No `MetricsProvider` inside the emitter proper (`svg.zig` walker takes a built `ir.Layout`); the one-shot `render()` is CLI glue with a stated same-files agreement.
- Core dist lib untouched: `b.dependency("zatex", .{ .cabi = false, ... })`; `tools/size_gate.sh` keeps passing unmodified.
- Determinism: same input + same font files = byte-identical SVG. Integer `viewBox`; fixed 2-decimal writer (round-half-away, strip zeros, `-0` → `0`); lowercase hex; no timestamps/paths in output.
- Flat `src/*.zig` (required by `tools/check_test_roots.sh`); single-root `refAllDecls` test shape (mathml precedent).
- Frequent commits: one per task minimum, only the files the task names.

Shared interfaces (every task uses these exact names):

```zig
// outlines.zig
pub const Outlines = struct {
    ptr: *const anyopaque,
    // Segments in per-face font units (y-up, like CFF), or null to skip ink.
    // Never errors: failure resolves to null (skip-ink totality).
    glyphSegs: *const fn (ptr: *const anyopaque, unified: u16, out: []cff.Seg) ?[]const cff.Seg,
    // Integer advance in thousandths of an em (500 fallback inside file impl).
    advance1000: *const fn (ptr: *const anyopaque, unified: u16) i32,
    // Per-face units-per-em (1000 when unknown; ink is skipped anyway then).
    upmOf: *const fn (ptr: *const anyopaque, unified: u16) u16,
    // Ink box in thousandths, y-up, origin-relative [l, b, r, t]; zeros on failure.
    inkThou: *const fn (ptr: *const anyopaque, unified: u16) [4]i32,
};
```

```zig
// svg.zig
pub fn renderLayout(layout: zatex.ir.Layout, ol: Outlines, segs: []cff.Seg, out: []u8) zatex.LayoutError![]u8;
pub fn render(source: []const u8, options: zatex.LayoutOptions, prov: zatex.MetricsProvider, ol: Outlines,
    runs: []zatex.ir.Run, rules: []zatex.ir.Rule, glyphs: []u16, segs: []cff.Seg,
    out: []u8, diag: *zatex.Diag) zatex.LayoutError![]u8;
```

Bake formula (SVG y-down, baseline at `oy`; `s = size_units/upm`,
`kx = x_scale/1000`, `kh = x_shear/1000`, `mx = mirrored ? -1 : 1`):

```
X = ox + mx·s·kx·x + mx·kh·(y·s)
Y = oy − s·y
```

Path soup rule: track the pen; emit `M` when a segment's start differs
from the pen, else `L`/`C` continuation; emit `Z` when a segment's end
equals its subpath start.

Rules (in order): for each `Rule`, `paintOf(r.color)`; `diag == .none`

pen `x_units = run.x`, per glyph:
`face segs = ol.glyphSegs(...) orelse { step; continue }`;
`s = size/unified-upm`; bake each point with the File-map formula;
soup rule (`M` on pen mismatch, `L`/`C`, `Z` when a segment ends at
its subpath start); pen steps `divTrunc(advance1000*size,1000)` then
`divTrunc(step*x_scale,1000)` (render.zig:122-127 parity).
Shifts: replicate `leftShiftUnits`/`rightShiftUnits` over
`ol.inkThou` + `ol.advance1000` (mirror branches `[-r,-l]`, shear
extremes via ink top/bottom, rule rect edges); `viewBox` from the
