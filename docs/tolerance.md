# docs/tolerance.md — Differential tolerance policy (issue #11)

The required differential gate (`packages/zatex-core/src/parity.zig`,
"sweep agreement with pinned KaTeX") compares this engine against
pinned KaTeX 0.18.7 output
(`packages/zatex-core/goldens/katex_sweep.json`, regenerated by
`npm run sweep` in `tools/katex`). Per AGENTS.md §4, required gates
compare layout IR /
MathML text, never rendered pixels.

## What must agree exactly

1. **Accept/reject.** For every sweep row, both engines accept or both
   reject. Any disagreement fails, unless the row is a declared
   divergence (see below).
2. **Reject position.** Rejects surface as `error.Invalid`, and when
   KaTeX reports an error position (`katex_pos`), our `Diag.offset`
   must equal it. Macro-table errors carry no position on either side
   and are exempt.
3. **Accept structure.** For accepts, our MathML tag sequence must equal
   KaTeX's after the normalizations below. Tag *sequence* only:
   attribute values (spacing widths, exact variants) are out of scope —
   those depend on font metrics, and same input + same font metrics is
   covered separately by the reference-host determinism probes
   (`packages/zatex-core/src/refhost.zig`).

## Normalizations (documented equivalences)

- Envelope tags `math` / `semantics` / `annotation` carry no layout and
  are dropped from both sides.
- `\font` commands emit an `mstyle mathvariant` wrapper while KaTeX
  pushes the variant onto leaves; the wrapper shell is dropped,
  children pass through.
- `\href` emits an `mrow href` wrapper while KaTeX puts `href` on the
  child; the wrapper shell is dropped, children pass through.

Adding a normalization requires a comment here explaining why the two
shapes carry identical layout meaning. Normalizations never hide an
accept/reject or position difference.

## Declared divergences

Rows with `katex_only: true` document behavior where we intentionally
differ (currently 5: `\text`-mode `$` handling and friends). Each such
row records our error in `ours`, and the test asserts exactly that
error. A divergence that stops diverging (KaTeX changes, or we close
the gap) fails loudly: unexpected acceptance of a `katex_only` row is
an error, forcing the row back to full agreement.
